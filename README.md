# System Design Notes - Interactive Visualizer

Interactive React + Vite learning platform based on System Design Interview concepts.

## Current Scope

This project intentionally focuses on **Chapter 1 through Chapter 8 only**.

- Chapter 1: Scale from Zero to Millions of Users
- Chapter 2: Back-of-the-Envelope Estimation
- Chapter 3: Framework for System Design Interviews
- Chapter 4: Design a Rate Limiter
- Chapter 5: Design Consistent Hashing (modularized as Module 0/1/2 + Comparison Lab)
- Chapter 6: Design a Key-Value Store
- Chapter 7: Design a Unique ID Generator
- Chapter 8: Design a URL Shortener

Chapters 9 through 16 are currently out of scope.

## Run Locally

Prerequisite: Node.js

1. Install dependencies
   npm install
2. Start dev server
   npm run dev
3. Type-check
   npm run lint
